## 🚀 Déploiement

### Installation locale

1. Cloner le repository :
```bash
git clone https://github.com/loladn/portfolio.git
```

2. Ouvrir le fichier `index.html` dans un navigateur web

### Serveur web

Pour le formulaire de contact (PHP), un serveur web avec support PHP est nécessaire :

```bash
# Avec PHP built-in server
php -S localhost:8000
```

Puis accéder à `http://localhost:8000` dans votre navigateur.

### Hébergement

Le site peut être déployé sur n'importe quel hébergeur web supportant HTML/CSS/JS et PHP :
- GitHub Pages (sans formulaire PHP)
- Netlify / Vercel
- Hébergement web traditionnel (OVH, Ionos, etc.)
